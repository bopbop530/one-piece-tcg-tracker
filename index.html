Rows marked ? are Extra and Premium Boosters, whose per-pack rarity structure Bandai has never published. Their box and pack counts are confirmed; the rarity split is inferred from each set's own card pool, so read those returns as rough.
Return is expected sealed value against box price, before you sell anything. It is an average across infinite boxes — not what your box will do. A set can show +30% and still brick nine boxes out of ten if Top-5 share is high.

Supply signal — cheap copies drying up

Card Set Market Floor Floor / market 13-day Supply Call Last seen
There is no free eBay listing-count or PSA population feed, so this is not TCGQuant's exact input. What every card does have is a lowest listing and a recent sold average. When the floor climbs toward the market price, the cheap copies are gone — that is supply tightening, measured rather than guessed. A floor above market is not automatically bullish either: market price is a lagging sold-average, so that gap can mean a card is running or simply that one overpriced listing is sitting on a card nobody has traded. That is why a call needs the 13-day trend to confirm it, and why anything last priced over 30 days ago is refused rather than ranked. Click any row for its history.

Box prices

No free API exists for sealed product, so these ship as estimates. Anything you edit turns gold and is saved to this browser. Put in what you actually pay.

Pull rates

Bandai publishes nothing. Community tables disagree with each other and most do not even sum to a real box. These do. Adjust them to match what you actually pull — every number in the app moves with them.

Pick a profile to set every set of that type at once, or pick a single set to override just that one — sets marked ✎ have their own rates. Slot pool sizes are already per-set everywhere, so a set with 5 Manga Rares gives each one a fifth of the odds without you doing anything.
